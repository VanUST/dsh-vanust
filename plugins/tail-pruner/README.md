# @cc/dsh-tail-pruner — обрезка результатов инструментов от хвоста

Провайдер, который кэширует префикс промпта, заново считает всё после первого изменённого
байта. Харнесс обрезает результаты инструментов только когда контекст уже выше порога
компакции, и `@deepseek-ai/dsh-compaction-tool-result-pruner` переписывает **все** результаты
больше 8192 символов начиная с самых старых. Самая ранняя переписанная вершина стоит у
начала истории, поэтому следующий запрос оплачивает почти весь контекст.

Измерено 2026-11-20 по трём суткам этого развёртывания (22 938 шагов, 5.56 млрд токенов
промпта, 99.13% из кэша): 53 прохода обрезки оплатили **12,2 млн** свежих токенов из
48,2 млн; чистая переоплата по всем причинам — 9,4 млн.

Плагин меняет политику на **хвостовую**. Перед шагом он измеряет сессию тем же tokenMeter,
что и харнесс, и сравнивает с бюджетом (окно x `budgetRatio`, 0.45 по умолчанию — ниже
порога компакции 0.5 на 1M-окне). Выше бюджета он переписывает результаты **от новейших** и
останавливается, как только проекция опустилась под бюджет. Последние `protectResults`
результатов не трогаются: модель сохраняет те входы, с которыми работает сейчас.

## Конфигурация

```yaml
- insert:
    - id: tail-pruner
      name: '@cc/dsh-tail-pruner'
      config:
        budgetRatio: 0.45      # доля окна модели; ниже порога компакции
        thresholdChars: 8192   # кандидат — результат больше этого
        headChars: 4096        # сколько головы оставить
        tailChars: 1024        # сколько хвоста оставить
        protectResults: 3      # сколько новейших результатов не трогать
        routes:                # необязательно: бюджет по маршруту
          - provider: openai-codex
            budgetRatio: 0.75
        # enabled: false
```

## Что делает и чего не делает

- Слушает `agent/pre-step` (prepend): обрезка происходит до проверки компакции, поэтому порог
  компакции не достигается и прежний обрезчик не срабатывает.
- Пишет те же два долговечных события, что и харнесс: `compaction/prune` (цена затенённой
  вершины) и замену `tool/result` с `surfaceOp: replace` и `sourceEventSeqs`. Воспроизведение
  сессии остаётся точным, полный текст — в исходном событии журнала.
- Прежний обрезчик и компакция остаются смонтированными страховкой: если кандидатов нет,
  работает старый путь.
- Не трогает ответы модели, пользовательские сообщения и результаты моложе `protectResults`.
- Если у сессии ещё нет `contextWindow` (маршрут не выбран), плагин молчит.
