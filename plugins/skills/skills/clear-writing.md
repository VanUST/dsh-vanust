# Clear writing

Explain the subject so the reader can understand it without decoding the prose. Follow the "80% of the way to ASD-STE100" style: short sentences, common words, one name per concept. This is a style preference, not a compliance score.

1. Identify the reader's question and the facts that answer it.
2. Give the main idea, then build the explanation in a useful order.
3. Use common words, concrete subjects, and active verbs. Define necessary terms.
4. Keep one name for each concept. Remove decorative synonyms and stock phrases.
5. Aim for 25 words or fewer per descriptive sentence and 20 per instruction. Keep one topic per paragraph; split paragraphs longer than six sentences.
6. Give one instruction per sentence. Put a prerequisite before the action. Break long noun groups into phrases that show how the parts relate.
7. Remove needless words, then read for meaning. Preserve facts, uncertainty, units, exceptions, and the user's voice. Keep natural phrasing when it helps.

Return the requested text. Add explanation about edits only when useful or requested.

## Strict ASD-STE100

If the user asks for a strict draft, use an official copy of the current issue's rules and dictionary. If those are unavailable, produce a clearly labeled STE-inspired draft and state what remains unverified. Never claim compliance from short sentences alone.

## Example

Before: "It is imperative that the operator ensures the valve is closed prior to operation."

After: "Before you start the operation, close the valve."
