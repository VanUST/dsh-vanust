Убрать шов, из-за которого панель задач читает устаревший файл: на доске больше 512 КБ экспорт `taskboard.json` обновляется только по порогу снимка, а панель (`client.js:9, :248`) читает файл напрямую и покажет состояние на момент последнего снимка. Перевести панель на чтение через серверный API плагина, чтобы видимые данные всегда были свежими, не возвращая при этом перезапись всей доски на каждую операцию.
