Сделать доску задач масштабируемой на долгие проекты без поломок: источником истины становится журнал событий (append-only, сливаемый между машинами) плюс периодический текстовый снимок, а не один JSON на 13 МБ. Запись операции перестаёт перезаписывать всю доску, чтение становится «снимок + хвост журнала», полный проигрыш остаётся только путём восстановления. Совместимость сохраняется: taskboard.json остаётся производным экспортом, CAS по revision, блокировка доски, номера seq, проекции — на месте. Эквивалентность доказывается побайтным сравнением с результатом старого кода на той же последовательности операций.
