Построить единый визуальный слой экосистемы состояния: одна панель с четырьмя режимами — бизнес-требования, доска задач, карта дизайна, тесты и трассировка — и сквозной взаимосвязью между ними. Решения согласованы владельцем 2026-11-17: (1) одна панель с режимами, плюс отдельная панель бизнес-требований, с учётом взаимосвязи всего; (2) read-only линзы по сгенерированным проекциям, без записи из панели в первой версии; (3) начинать только после завершения бэкенда v1; (4) карта — существующий xyflow-рендерер сцены. Причина: сегодня это три независимых хранилища и три панели (Tasks 92 КБ client, карта 525 КБ + 3.4 МБ кадр, кейсы 50 КБ), а таргет-дизайн уже объявляет доску, трассировку и карту производными одного state/. Объединение делается на уровне проекций: панель — новый клиент-плагин, владельцы данных остаются прежними.
