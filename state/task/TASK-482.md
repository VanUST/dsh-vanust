Почини ручную смену статуса в панели состояния. Сейчас владелец не может поменять статус: клиент читает строку доски через /taskboard get и не находит ревизию, затем отказывает с «the board row carries no revision». Сделай: (1) воспроизведи на одной из строк (TASK-383, TASK-372, TASK-438, TASK-337, TASK-273) и покажи, что именно возвращает /taskboard get для неё — есть ли там revision, boardId, и чем эта строка отличается от свежей; (2) назови причину: строка пришла из старого формата, get отдаёт усечённое представление, или задача вообще без пары в доске; (3) исправь в одном месте — либо get отдаёт ревизию, либо клиент берёт её законным путём (например через list/owner-status без CAS для строк без ревизии, с явной пометкой), но без подстановки нуля и без молчаливого обхода; (4) докажи: смена статуса проходит для каждой группы статусов на реальной доске (на одноразовой копии), и отказ больше не утверждает «no revision» там, где ревизия есть. Верни коды, что печатал get до и после, и что осталось непокрытым.
