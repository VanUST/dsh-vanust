Дать агентам один инструмент, который выполняет набор операций над задачами за один шаг: создать, обновить, добавить заметку, закрыть, отменить — в указанном порядке, с однократным чтением и однократной записью доски, с компактным отчётом по каждой операции и с сохранением всех действующих гейтов (базис требования, зависимость, причина отказа, доказательство при закрытии). Существующие отдельные инструменты остаются и работают как раньше.
