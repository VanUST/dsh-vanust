Починить путь восстановления проекции выдачи: полный текст спроецированного результата снова читается агентом при любом размере файла. Сейчас read входит в список проецируемых инструментов (порог 8192 Б), поэтому чтение файла из .dsh/spill снова проецируется и середина недоступна; proof этого не видит, потому что читает файл через readFileSync, а не через инструмент. Сделать: (1) чтение по пути из спилла не проецируется (исключение по расположению файла), (2) отдельный, более высокий порог для read (например 64 КиБ), чтобы обычный документ читался целиком, (3) proof проверяет именно путь агента: прогоняет настоящий слушатель tools/post-execute на фейковом exec, получает баннер, затем повторно прогоняет через слушатель чтение по пути из баннера и требует, чтобы результат остался полным и не проецировался, (4) негативный контроль доказывает, что на старом коде этот proof падает. Перепаковать плагин с подъёмом версии, обновить docs/PLUGIN-PROOFS.md, если он описывает упаковку.
