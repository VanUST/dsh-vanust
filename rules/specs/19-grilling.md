## 5. Grilling Option (grill-me)

Run a grilling session before any work when the user asks to be grilled ("grill me",
"stress-test my plan", "tear this plan apart", "sharpen this design") — and whenever the ask
is ambiguous. Ambiguity is itself the trigger; do not wait to be asked.

**Any one of these makes the ask ambiguous:**

- **A bare continuation** — "continue", "go on", "keep going": it carries no objective, so
  state what you are about to continue and get it confirmed.
- **A defect ask with no reproduction and no location** — "fix the bugs", "it's broken", "the
  tests fail": which bug, which failure, and where it shows up are all missing.
- **A quality adjective with no criterion** — "make it better", "optimise", "clean up": a
  direction is not a target, and an unmeasurable target cannot be reported as reached.
- **A multi-goal ask with no priority** — priorities decide the order, and the order decides
  what is abandoned when time runs out.
- **A scope-free verb** — "update the docs", "add tests", "refactor this": the verb names an
  activity, the scope names the work.

**Before any work, state all four and get them confirmed:** the **objective** (one sentence,
no vague verb — what will be true when the work is done), the **scope** (the paths or the
subsystem it may touch, named concretely), the **proof** (the command that shows it done and
the output it will print, or an explicit statement that nothing measures it yet and what
would), and the **constraints** (what must not change, and whose authority the work needs).

**Propose, do not interrogate.** Put your best reading of all four to the user for
confirmation, one question at a time, each with a recommended answer, resolving the decisions
branch by branch. Look the facts up rather than asking: the facts are yours to find, the
decisions are the user's.

Take no action until the user confirms shared understanding. This holds for research as well
as implementation — research is looser about the record, never about the four fields. Nothing
enforces this, so state them because this rule says so.
