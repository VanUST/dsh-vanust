What the data says

  • 98.8% of all tokens were cache hits — 25,044,559,088 of 25,343,875,817. The cost lever is therefore cache behaviour, not raw token volume: only 299,316,729 tokens were billed at the full rate.
  • The non-Flash tier accounted for 0.8% of spend ($7.3105). The Flash-only policy is a predictability and blast-radius control on this data, not a large saving: the tier it forbids was already a rounding error by spend.
  • The export referenced 5 distinct API key name(s). This report deliberately does not say which.
Aggregated from a DeepSeek platform usage export: cost-2026-09-04_2026-10-03.csv, amount-2026-09-04_2026-10-03.csv. The export files are not in this repository — they carry an account id, partially masked API key strings and the key names in use, none of which a cost report needs. Regenerate the analysis with node scripts/usage-analytics.mjs --export <usage.zip> --out-dir docs/usage (or make usage), which drops those columns at the parse boundary, groups the keys under opaque use-case-N labels, and re-reads its own output before writing it.
